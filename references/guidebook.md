# 用户自助操作路径

用户问"我该去哪儿关"时用这份。**先教方法，再给路径**——厂商改版频繁，路径会失效，搜索框不会。

## 最可靠的方法：设置里直接搜

打开「设置」，右上角或顶部有搜索框（放大镜图标），直接输入下面这四个词，第一项通常就是要找的页面：

`设备管理` · `无障碍` · `通知使用权` · `悬浮窗`

这比记路径可靠。下面给的路径只作参考，找不到就用搜索。

## 四类关键控制权

### 1. 设备管理员

能阻止卸载、锁屏、清数据的应用。**关闭前先确认它不是手机找回服务**，否则会失去定位找手机的能力。

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi | 设置 → 密码与安全 → 系统安全 → 设备管理器 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 设备管理器 |
| OPPO / 一加 / realme | 设置 → 密码与安全 → 系统安全 → 设备管理器 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 设备管理器 |
| 三星 | 设置 → 生物识别和安全 → 其他安全设置 → 设备管理应用 |
| 原生 Android | 设置 → 安全 → 设备管理应用 |

**不要关的**：查找我的设备 / 手机找回 / 云服务 / 工作资料 / 企业 MDM。这些关了，手机丢了就找不回来。

### 2. 无障碍服务

能读屏幕、代替点击。这是权限等级最高的一项。

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 |
| OPPO / 一加 / realme | 设置 → 系统设置 → 无障碍 |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 |
| 三星 | 设置 → 辅助功能 → 已安装的应用程序 |
| 原生 Android | 设置 → 无障碍 |

**正常会开的**：输入法（讯飞、搜狗）、屏幕朗读、自动点击器、部分车机互联。如果关掉后发现某个输入法不能用了，回来再打开。

### 3. 通知使用权

能看到所有 App 弹出的通知，包括验证码。

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi | 设置 → 通知与状态栏 → 通知使用权 |
| 华为 / 荣耀 | 设置 → 通知 → 通知使用权 |
| OPPO / 一加 / realme | 设置 → 通知与状态栏 → 通知使用权 |
| vivo / iQOO | 设置 → 通知与状态栏 → 通知使用权 |
| 三星 | 设置 → 通知 → 高级设置 → 通知使用权 |
| 原生 Android | 设置 → 通知 → 设备与应用通知 → 特殊访问权限 |

**正常会开的**：智能手表配套 App、车载、通知管理工具。关了手表可能收不到消息。

### 4. 悬浮窗

能在任何界面之上弹内容，弹窗广告就靠这个。

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi | 设置 → 应用设置 → 特殊权限 → 显示在其他应用上层 |
| 华为 / 荣耀 | 设置 → 应用 → 权限管理 → 悬浮窗 |
| OPPO / 一加 / realme | 设置 → 应用管理 → 特殊应用权限 → 悬浮窗 |
| vivo / iQOO | 设置 → 应用与权限 → 权限管理 → 悬浮窗 |
| 三星 | 设置 → 应用 → 特殊访问权限 → 显示在其他应用上层 |
| 原生 Android | 设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 |

**正常会开的**：微信/QQ 气泡、录屏、翻译悬浮球。

## 卸载类操作

普通用户能做的卸载只有一种：长按图标 → 卸载，或在 设置 → 应用 → 应用管理 里选应用 → 卸载。

会遇到的三种情况：

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 卸不掉，按钮是灰的 | 它拿到了设备管理员 | 先去第 1 项关掉管理员，再回来卸 |
| 卸掉后过几天又出现 | 有同源应用在把它装回来 | 先卸载装它的那个应用，顺序反了没用 |
| 提示"系统应用无法卸载" | 在系统分区 | 不用管，正常现象 |

**不要为了卸一个软件去 root 或刷机。** 代价远大于收益。

## 关掉通知（比卸载更有效）

老年用户手机"叮叮响"多半不是应用本身，是通知没关。

设置 → 通知与状态栏 → 通知管理 → 找到那个应用 → 关掉"允许通知"，或者只保留"消息"类别，把"推广""活动""推荐"之类的类别单独关掉。

这条路径的收益通常比卸载应用更大，优先教这个。

## 广告来源排查（按命中率排序）

| 来源 | 特征 | 处理 |
|---|---|---|
| 快应用 | 从浏览器、负一屏、锁屏点出来的"应用"，实际没装 APK | 设置里搜"快应用"，关闭通知和跳转权限 |
| 负一屏 | 桌面右滑出现的资讯流 | 桌面设置里关掉"智能助手""负一屏" |
| 系统浏览器推送 | 通知栏出现新闻推送，点开是浏览器 | 浏览器设置里关推送，或直接禁用 |
| 锁屏画报 | 锁屏界面出现广告图 | 设置搜"锁屏画报"，关闭 |
| 输入法推送 | 键盘上方出现推荐词或活动 | 输入法设置里关"热点""资讯" |
| 第三方 App 弹窗 | 解锁后突然全屏广告 | 查悬浮窗权限（见第 4 项） |

这五类占了中老年手机广告的绝大多数，而且**都不需要卸载应用**。

## 恢复被卸载的应用

从官方应用商店重新安装即可，但**应用内的数据通常找不回来**（聊天记录、游戏进度、本地保存的内容）。

如果用户还没删，先提醒这一点：卸载前确认里面没有需要保留的东西。

## 鸿蒙用户看这里

### HarmonyOS 2 / 3 / 4

底座是安卓，上面所有华为机型的路径通用，报告也按安卓的方式生成。**在设置顶部搜索框搜关键词最快**：`设备管理`、`无障碍`、`通知使用权`、`悬浮窗`。

### HarmonyOS NEXT（纯血鸿蒙）

不再兼容安卓，路径变了：

| 要找的东西 | 路径 |
|---|---|
| 设备管理 | 设置 → 隐私和安全 → 更多安全设置 |
| 无障碍 | 设置 → 辅助功能 → 无障碍 |
| 通知使用权 | 设置 → 通知和状态栏 → 通知使用权 |
| 悬浮窗 | 设置 → 应用和服务 → 权限管理 → 悬浮窗 |
| 应用列表 | 设置 → 应用和服务 → 应用管理 |

NEXT 上很多安卓时代的第三方清理、安全类 App 根本装不了，所以广告和流氓软件的来源比安卓少。真正要看的是：**系统自带服务里的推送开关**、**快应用**、**浏览器推送**。

同样可以在设置顶部搜索框直接搜关键词。
