run.bat
它自己认手机，认完就采集、归因、出报告。不用再跑第二条命令。

--rebuild 只重新归因和出报告，不碰手机。安卓 / 鸿蒙用不到这条。

最该先看的一项：第三方键盘的「完全访问」

开了这个开关的第三方键盘，能看见你在任何 App 里打的字。密码、验证码、银行卡号，都算。

你要是没主动开过，它就是关着的。不确定就去第 4 项看一眼。

3 项必查，5 项看情况

报告里只把这 3 项留成待核对，因为它们是「别人动过你手机」最直接的痕迹。每项三句话：在哪、什么算有问题、怎么处理。

1

配置描述文件 / 设备管理

设置 → 通用 → VPN 与设备管理
有问题列表里有你不认识的「配置描述文件」或「设备管理」。这玩意能塞 Wi-Fi、证书、书签，还能锁住你的设置。
怎么处理点进去看是谁装的。不认识就截图留证，再删掉。公司发的手机别乱删，删了可能连不上公司 Wi-Fi 和邮箱。
2

Apple ID 登录的设备

设置 → 最上面你的名字 → 设备列表
有问题有不认识、也没印象登录过的设备。别人的设备登着你的账号，就能看到你的照片、备忘录、短信。
怎么处理点那台设备 → 从账户中移除。然后马上改密码，把双重认证打开。
3

位置共享

查找 App → 底部「我」 → 共享我的位置
有问题共享给了你不想给的人。偷偷盯住一个人，在 iPhone 上最常见就是这么干的，而且还是你自己点过同意的。
怎么处理点那个人 → 停止共享我的位置。对方会收到提示，是家人的话先说一声。
另外 5 项：也有问题，但没那么急

这 5 项一样会造成实际损失，只是不像上面 3 项那样直接指向「有人动过你手机」。有空再看。

4

第三方键盘的完全访问

设置 → 通用 → 键盘 → 键盘 → 点开第三方键盘
有问题「允许完全访问」是开着的。开了它，这个键盘能看见你在任何 App 里打的字，密码和验证码也算。
怎么处理把「允许完全访问」关掉。不用的键盘直接删。关掉之后语音输入和云同步会用不了，这是正常的。
5

屏幕使用时间

设置 → 屏幕使用时间
有问题不是你设的，密码也不在你手里。知道这页密码的人，能看你每个 App 用了多久、什么时候用的，还能不让你装软件、不让你删软件。
怎么处理别人设的，得要他给密码才能关。关不掉这件事本身就有问题。
6

App 的定位权限

设置 → 隐私与安全性 → 定位服务
有问题有你很少用、却拿到「始终允许」的应用。一个不该知道你位置的应用拿到这个，就是在一直跟着你。
怎么处理用不上的改成「使用 App 期间」或「永不」。这页最下面有个「重要地点」，记着你去过的所有地方，介意就关掉。
7

VPN 与网络中转

设置 → 通用 → VPN 与设备管理 → VPN
有问题VPN 列表里有你不认识的配置。第三方 VPN 能看到你所有的上网记录，有些免费加速器就是靠卖这个赚钱。
怎么处理点进去删掉。要是描述文件下发的，回到第 1 项把描述文件删了。
8

快捷指令自动化

快捷指令 App → 底部「自动化」
有问题有你没设过的规则。它能做到「一到家就自动把位置发给某人」，设一次就长期有效，而且在设置里找不到。
怎么处理左滑，删掉。

顺序有讲究。第 1、2 项如果有问题，先处理完，再谈别的应用。描述文件和账号被人登录，优先级高于一切。

别去 App Store 装「清理大师」「安全卫士」

iOS 不允许一个 App 读另一个 App 的数据。这类软件能扫的只有它自己的缓存，扫完给你看一堆没用的数字。

对偷拍、偷听、被跟踪，它们一点用都没有。真想查，看的就是上面那 3 项设置。

报告说某个软件是企业证书装的

特征是这个软件在 App Store 搜不到。企业证书版随时会被苹果封掉，封了就打不开，你也没法更新。

正确做法：去 App Store 装它的正式版，装好登录，确认能用，再删掉企业证书那个。别反过来。

连不上的时候，按这个顺序试

换一根数据线。很多线只有充电功能，没有数据功能。
换一个 USB 口，别用扩展坞和前面板。
Mac 上先跑一次 adb kill-server，再重插。
Windows 要装手机厂商的 USB 驱动，装完重启。
手机上把 USB 模式从「仅充电」改成「传输文件」。
还是没有？在开发者选项里点「撤销 USB 调试授权」，重新插，重新点允许。

常见问题

点开看答案。

手机上要装 App 吗？
不用。整套东西装在电脑上，手机端零安装。你只要插一根线。
会不会把我手机里的东西传走？
不会联网上传。采集结果只写进你自己电脑上的 ./phone-audit 目录，报告也是本地文件。
会不会自己把我软件删了，或者改我设置？
不会。整套脚本里没有一条写命令：不卸载、不清数据、不改设置、不授予权限、不替你点按钮。它只读，然后告诉你该去哪个设置里点。
我不是技术员，能跑得动吗？
能。就一条命令，复制粘贴，路径参数默认就行。采集、归因、出报告全在这一条里。认得手机就不用你再做判断。
iPhone 能查出被监控吗？
能查一部分，而且是最要紧的那部分。自动能看到的只有装了什么、从哪装的；被跟踪、被定位、被同步这类，答案全在那 3 项设置里，得你自己点一遍。
为什么 iPhone 只能看到这么点？
因为 iOS 把每个 App 关在自己的沙箱里，一个 App 读不到另一个 App 的数据，电脑上的工具也一样。这是苹果的设计。不是工具偷懒，谁都读不到。
报告说没问题，是不是就安全了？
不能这么理解。它只说明这次读到的这些，没凑成说得通的问题。没读到的项不等于安全，只等于没看到。iPhone 上尤其如此，那 3 项你自己没核对，就等于没查。
要 root 或者越狱吗？
不用，也不该。为了查一个软件去 root，代价远大于收益：保修没了，系统更容易被攻破。不 root 一样能看到权限、安装来源、后台行为和网络连接。
Windows 电脑能用吗？
能，Windows 是正经支持的：仓库根目录有 run.bat，双击就跑。安卓和鸿蒙装好 adb 就行；iPhone 要先装 iTunes（或者苹果的设备驱动），不然电脑认不出手机。
会不会误报？
会。这套判断天生会误报，所以它不会单独拿一个信号下结论。「不是商店装的」「要了敏感权限」本身都不算问题，只有几件事凑到一起才值得说。报告里也会主动告诉你哪些不用管。
跑一遍要多久？
安卓一般 20 到 60 秒。iPhone 采集只要几秒，但那 3 项人工核对要花你两三分钟。
报告能发给别人看吗？
能，它是单个 HTML 文件，不依赖网络，手机上也能打开。但里面有你装了哪些软件的清单，发给别人之前自己先看一眼。

四条底线，先说在前面

这四句话如果有一条你不认同，那这套工具就不适合你。

只读，不写

没有一条命令会改动你的手机。看得到，碰不到。

不帮你点

哪一项该关、在哪个设置里、关掉会失去什么，都说清楚。最后那几步你自己点。

不是杀毒软件

没有病毒库可以比对。它看的是权限和行为有没有说不通的地方。

只反映那一刻

这是一次体检，不是持续防护。查完装了什么新软件，结论就变了。
